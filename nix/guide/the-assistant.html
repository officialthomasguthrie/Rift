Rift guide

The assistant

Rift runs a language model on the machine itself. There is no account, nothing is sent anywhere, and it works with the network unplugged. The model files are on your side of the drive.

Asking something

Type the question into the field of the Applications menu, or at a prompt:

rift ai "what is taking up space in my home folder"

The answer comes back as text. When the answer is a command that would change something, the command is shown and nothing runs until you say so. Add --yes to skip that question when you already know what you are asking for.

Which model runs

The model is chosen for the machine: a small one on a laptop with little memory, a larger one where there is room, and the graphics card is used when it can be. To see what is loaded:

rift ai

Finding a file by what is in it

Rift keeps an index of your home folder by meaning, not by exact wording, so you can look for a file by what it was about:

rift ai search "the letter about the flat"

The same index is what the field of the Applications menu looks through when you type plain words into it, and what the search field of Files searches on Enter.

The index is brought up to date every fifteen minutes, and rift ai index does it now. Notes, letters, code and PDFs all go into it. A PDF is read by a program that runs in a sandbox with no network and sees that one file, so a file from the internet cannot do anything else on the machine, and a PDF in the answer says which page the words are on:

~/notes/letter.pdf:page 2  2026-09-24

Words out loud

Rift can read words out loud in a voice that came with it. Nothing is sent anywhere for this either, and it works with the network unplugged:

rift ai say "the kettle has boiled"

The words come out of the speakers. To keep the sound instead of playing it, name a file:

rift ai say --wav kettle.wav "the kettle has boiled"

The voice is one of the files on your side of the drive, the same as the models, and rift ai says which one it is.

Speech written down

The other way round, Rift writes down what was said in a recording. The recording stays on the machine, the same as everything else here:

rift ai listen kettle.wav

The words are printed. A wav file is what it reads, which is what the line above writes and what a recorder on the machine saves. When nothing was said in the recording, it says so.

Other programs on the machine

The model is also served to programs on the machine at 127.0.0.1:11434, in the shape most tools expect. A request that comes from a web page is refused, so a page in the browser cannot reach it.
