Snapshots, backups and a second drive

Three different things keep your files: snapshots on the drive itself, backups on another disk, and a second drive that boots on its own.

Snapshots

A snapshot of your home folder is taken every hour, on the drive, and the first of each hour, day and week is kept for a while. A snapshot costs almost nothing until a file changes.

rift snapshot list
rift snapshot restore 2026-09-19T08:00:00Z Documents/notes.md

The file comes back beside the one that is there now, so nothing is overwritten unless you ask for that with --replace. Snapshots are on the same drive as the files, so they are for a mistake, not for a lost drive.

Timeline in Files does the same thing with the folder in front of you. See Files, disks and printers.

Backups

A backup is your home folder, encrypted and deduplicated, in a folder on another disk. Plug the disk in and Rift mounts it by itself.

rift backup now
rift backup list
rift backup restore 8a1c9f2e Documents/notes.md

The name of a backup comes from rift backup list. To choose which disk backups go to, mount it and run sudo vault target <folder>.

The backup has a key of its own, which is printed once when the disk is set up. Keep it somewhere other than the drive: without it the backup cannot be read.

A second drive

A clone is a whole second Rift: the system, your files, and a key of its own, so losing one drive does not lock you out of the other.

sudo rift clone

It only offers drives that are removable and not in use, and it asks you to type the serial number of the drive you mean before it writes anything.
