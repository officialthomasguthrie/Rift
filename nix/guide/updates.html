Rift guide

Updates

The drive has room for two versions of the system. The one you are running is never written to while it runs: a new version goes into the other slot, and the drive starts it at the next boot.

If a new version does not start

The boot loader counts the attempts. A version that fails to start three times is put behind the one that worked, and the machine comes back up on the version you had before. Nothing of yours is touched by any of this: your files are on the encrypted volume, which no update writes to.

Which version is running

rift --version
rift doctor

rift doctor also says which slot you booted from, how much room is left on your volume, and whether each of the system's services is running.

Getting a new version

Rift does not download updates for itself yet, and there is no release to download. When there is one, this page will say how to ask for it.
